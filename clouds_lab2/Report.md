## Описание сервисов Microsoft Azure из таблицы


### Управляемые реляционные базы данных

**Azure Database for MySQL / PostgreSQL**

Сервисы Azure Database for MySQL и PostgreSQL используются для размещения реляционных баз данных в управляемом виде. Пользователю не требуется заниматься настройкой серверов или обслуживанием СУБД — достаточно работать с данными и SQL-запросами.
В модели сервис отнесён к категории **Database**, так как его основная задача — хранение и обработка структурированных данных. Основное потребление связано со временем работы экземпляра базы и объёмом хранилища.


### Аналитика и обработка больших данных

**Azure Databricks, Azure HDInsight**

Azure Databricks и Azure HDInsight применяются для обработки больших объёмов данных и аналитических вычислений. Эти сервисы используются для построения ETL-пайплайнов, аналитики и распределённых вычислений на кластерах.
Они были отнесены к **Cloud Services / Analytics**, поскольку их ключевая роль — анализ данных, а не просто предоставление вычислительных ресурсов. Тарификация в основном зависит от времени использования вычислительных мощностей.


### Интеграция и перемещение данных

**Azure Data Factory**

Azure Data Factory используется для организации процессов загрузки, передачи и преобразования данных между различными источниками. Сервис выполняет роль оркестратора и позволяет автоматизировать работу с данными.
В классификации он относится к аналитическим облачным сервисам, а оплата зависит от количества выполняемых операций и объёма передаваемых данных.


### Хранилища для аналитических данных

**Azure Data Lake Store**

Azure Data Lake Store применяется для хранения больших объёмов данных, предназначенных в первую очередь для аналитики. Это централизованное хранилище, из которого данные используются аналитическими и вычислительными сервисами.
Основное потребление связано с объёмом хранимых данных и количеством операций доступа.


### Потоковая аналитика

**Azure Stream Analytics**

Azure Stream Analytics используется для обработки потоковых данных в реальном времени. Сервис позволяет анализировать данные сразу по мере их поступления.
Потребление ресурсов определяется объёмом обрабатываемых данных и используемыми вычислительными единицами.


### Кэширование данных

**Azure Cache for Redis**

Azure Cache for Redis предназначен для ускорения работы приложений за счёт хранения часто используемых данных в оперативной памяти. Это снижает нагрузку на основные базы данных и уменьшает задержки.
Оплата зависит от времени работы и размера используемого кэша.


### Мониторинг и уведомления

**Azure Monitor**

Azure Monitor используется для отслеживания состояния ресурсов и приложений, а также для отправки уведомлений о событиях и сбоях.
В классификации он относится к инструментам управления, а потребление определяется количеством отправленных уведомлений и событий мониторинга.


### Резервное копирование

**Azure Backup**

Azure Backup применяется для хранения резервных копий виртуальных машин и данных. Сервис позволяет восстановить данные в случае сбоев или потери информации.
Основные факторы тарификации — объём хранимых данных и количество защищённых ресурсов.


### Доставка контента

**Azure CDN**

Azure CDN используется для быстрой доставки контента пользователям за счёт размещения данных на распределённых узлах по всему миру.
Стоимость зависит от объёма переданного трафика.


### Вычислительные ресурсы

**Виртуальные машины Azure, Azure Batch**

Виртуальные машины Azure предоставляют вычислительные ресурсы для выполнения различных задач, от простых сервисов до высокопроизводительных вычислений. Azure Batch используется для запуска массовых и параллельных вычислительных задач.
В обоих случаях основным параметром потребления является время использования вычислительных ресурсов.
